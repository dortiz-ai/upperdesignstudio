# Ejemplos de piezas

Guarda aquí piezas reales para que Claude afine reglas y plantillas:

- `aprobadas/`: piezas publicadas, con una línea de por qué funcionan.
- `rechazadas/`: piezas que no pasaron revisión, con el motivo.
- `requerimientos/`: requerimientos reales de campañas, tal como llegan al equipo.

Nombra los archivos con la fecha y la campaña, por ejemplo `2026-11_black-friday_feed.png`.
